#Python básico desde cero

¡Bienvenido/a! 👋

Este repositorio está dedicado al aprendizaje de Python desde cero, mediante explicaciones, ejemplos y ejercicios prácticos diseñados para desarrollar tus habilidades de programación paso a paso.

No necesitas tener conocimientos previos de programación. Lo único que necesitas es curiosidad, paciencia y ganas de aprender.

El objetivo es que comprendas los fundamentos de Python y seas capaz de utilizarlos para resolver problemas por tu cuenta.

Requisitos e instalación

Antes de comenzar, te recomiendo preparar tu entorno de desarrollo.

1. Instalar Visual Studio Code

Te recomiendo utilizar Visual Studio Code, un editor de código gratuito que facilita la escritura, ejecución y organización de tus programas.

2. Instalar Python

Para seguir los ejercicios, te recomiendo utilizar Python 3.14.x, ya que esta será la versión de referencia utilizada en los ejemplos y tutoriales de este repositorio.

Puedes descargarlo desde su página oficial:

https://www.python.org/downloads/

💻 Ejercicios

Los ejercicios están organizados por tema y dificultad. Te recomiendo resolverlos en orden, ya que algunos requieren conocimientos adquiridos en ejercicios anteriores.

Importante: intenta resolver cada ejercicio por tu cuenta antes de consultar una solución. Equivocarse forma parte del aprendizaje; comprender por qué te equivocaste es lo que te permite mejorar.

1. Variables y tipos de datos

Aprenderemos a almacenar información, asignar valores a variables y trabajar con diferentes tipos de datos.

Ejercicio 1.1: Suma de dos números

El programa debe solicitar al usuario dos números, sumarlos e imprimir el resultado.

Objetivo: aprender a declarar variables, recibir datos mediante input() y realizar una operación aritmética sencilla.

Ejercicio 1.2: Resta de dos números

El programa debe solicitar dos números, restar el segundo al primero e imprimir el resultado.

Objetivo: practicar el uso de variables y la resta.

Ejercicio 1.3: Datos personales

El programa debe solicitar el nombre, la edad y la ciudad del usuario. Después, debe mostrar toda la información en pantalla.

Objetivo: almacenar diferentes tipos de información y mostrarla mediante print().

Ejercicio 1.4: Conversión de tipos de datos

El programa debe solicitar la edad del usuario y convertir la entrada a un número entero antes de mostrarla.

Objetivo: comprender la diferencia entre texto y números, y aprender a utilizar int().

Ejercicio 1.5: Área de un rectángulo

El programa debe solicitar la base y la altura de un rectángulo, calcular su área e imprimir el resultado.

Objetivo: aplicar variables y operaciones aritméticas para resolver un problema práctico.

2. Operadores aritméticos

Aprenderemos a realizar operaciones matemáticas utilizando los operadores de Python.

Ejercicio 2.1: Operaciones básicas

El programa debe solicitar dos números y mostrar su suma, resta, multiplicación y división.

Objetivo: utilizar los operadores +, -, * y /.

Ejercicio 2.2: División entera y residuo

El programa debe solicitar dos números y mostrar el resultado de la división entera y el residuo.

Objetivo: aprender a utilizar los operadores // y %.

Ejercicio 2.3: Potencias

El programa debe solicitar una base y un exponente, calcular la potencia e imprimir el resultado.

Objetivo: utilizar el operador **.

Ejercicio 2.4: Promedio de tres calificaciones

El programa debe solicitar tres calificaciones, calcular su promedio e imprimir el resultado.

Objetivo: combinar varias operaciones aritméticas para resolver un problema.

3. Entrada y salida de datos

Aprenderemos a interactuar con el usuario mediante mensajes, entradas de información y resultados.

Ejercicio 3.1: Saludo personalizado

El programa debe solicitar el nombre del usuario y mostrar un saludo personalizado.

Objetivo: utilizar input() y print() para crear una interacción sencilla.

Ejercicio 3.2: Calculadora de edad

El programa debe solicitar el año de nacimiento y calcular una edad aproximada utilizando el año actual.

Objetivo: trabajar con entradas numéricas y operaciones aritméticas.

Ejercicio 3.3: Conversor de temperaturas

El programa debe solicitar una temperatura en grados Celsius y convertirla a Fahrenheit.

Objetivo: aplicar una fórmula matemática a los datos introducidos por el usuario.

4. Condicionales

Aprenderemos a tomar decisiones dentro de un programa mediante las estructuras if, elif y else.

Ejercicio 4.1: Número positivo, negativo o cero

El programa debe solicitar un número e indicar si es positivo, negativo o igual a cero.

Objetivo: utilizar condiciones para clasificar un valor.

Ejercicio 4.2: Número par o impar

El programa debe solicitar un número entero e indicar si es par o impar.

Objetivo: utilizar el operador módulo % junto con una condición.

Ejercicio 4.3: Mayor de dos números

El programa debe solicitar dos números e indicar cuál es mayor o si ambos son iguales.

Objetivo: utilizar operadores de comparación y estructuras condicionales.

Ejercicio 4.4: Aprobado o reprobado

El programa debe solicitar una calificación e indicar si el estudiante aprobó, de acuerdo con el criterio de aprobación establecido.

Objetivo: utilizar condiciones para evaluar un resultado.

Ejercicio 4.5: Calculadora básica

El programa debe solicitar dos números y una operación matemática. Según la operación seleccionada, deberá realizar una suma, resta, multiplicación o división.

El programa debe mostrar el resultado correspondiente y evitar realizar una división entre cero.

Objetivo: combinar entradas de datos, operadores aritméticos y condicionales para construir un programa más completo.

5. Ciclos o bucles

Aprenderemos a repetir instrucciones utilizando for y while.

Ejercicio 5.1: Contar del 1 al 10

El programa debe imprimir los números del 1 al 10 utilizando un ciclo.

Objetivo: comprender cómo funcionan las repeticiones.

Ejercicio 5.2: Tabla de multiplicar

El programa debe solicitar un número e imprimir su tabla de multiplicar del 1 al 10.

Objetivo: utilizar ciclos para automatizar operaciones repetitivas.

Ejercicio 5.3: Suma de números consecutivos

El programa debe solicitar un número entero positivo (n) y calcular la suma de todos los números desde 1 hasta (n).

Objetivo: utilizar acumuladores dentro de un ciclo.

Ejercicio 5.4: Adivinar el número

El programa debe establecer un número secreto y permitir que el usuario intente adivinarlo, indicando si cada intento es correcto.

Objetivo: combinar ciclos, condiciones y entradas de datos.

6. Listas y colecciones

Aprenderemos a almacenar varios elementos en una misma estructura y a trabajar con ellos.

Ejercicio 6.1: Lista de números

El programa debe crear una lista con varios números e imprimir todos sus elementos.

Objetivo: comprender cómo se crean y utilizan las listas.

Ejercicio 6.2: Suma de los elementos de una lista

El programa debe calcular la suma de todos los números almacenados en una lista.

Objetivo: recorrer una colección y acumular resultados.

Ejercicio 6.3: Encontrar el número mayor

El programa debe recibir varios números y determinar cuál es el mayor.

Objetivo: comparar elementos y obtener información de una colección.

Ejercicio 6.4: Lista de tareas

El programa debe permitir almacenar varias tareas y mostrarlas en pantalla.

Objetivo: practicar la administración básica de listas.

7. Cadenas de texto

Aprenderemos a trabajar con texto y a utilizar operaciones propias de las cadenas de caracteres.

Ejercicio 7.1: Contar caracteres

El programa debe solicitar una palabra e indicar cuántos caracteres contiene.

Objetivo: utilizar la función len().

Ejercicio 7.2: Convertir texto

El programa debe solicitar una frase y mostrarla en mayúsculas y minúsculas.

Objetivo: utilizar los métodos upper() y lower().

Ejercicio 7.3: Invertir una palabra

El programa debe solicitar una palabra e imprimir sus caracteres en orden inverso.

Objetivo: practicar el manejo de cadenas de texto.

8. Funciones

Aprenderemos a organizar el código en bloques reutilizables mediante funciones.

Ejercicio 8.1: Función de saludo

Crear una función que reciba un nombre y muestre un saludo personalizado.

Objetivo: aprender a definir y llamar funciones.

Ejercicio 8.2: Función para sumar

Crear una función que reciba dos números y devuelva su suma.

Objetivo: comprender los parámetros y el valor de retorno mediante return.

Ejercicio 8.3: Función para calcular el área

Crear una función que reciba la base y la altura de un rectángulo y devuelva su área.

Objetivo: utilizar funciones para resolver problemas matemáticos.

9. Manejo básico de errores

Aprenderemos a anticipar algunos errores y a evitar que ciertas entradas inválidas interrumpan el funcionamiento del programa.

Ejercicio 9.1: División segura

Crear un programa que solicite dos números y gestione el caso en el que el divisor sea cero.

Objetivo: validar datos y prevenir errores de cálculo.

Ejercicio 9.2: Entrada numérica válida

Crear un programa que solicite un número y gestione el caso en el que el usuario introduzca texto no numérico.

Objetivo: utilizar try y except para manejar excepciones.

10. Proyectos prácticos

Aplicaremos los conocimientos adquiridos para construir programas que combinen varios conceptos.

Proyecto 10.1: Calculadora completa

Desarrollar una calculadora que permita realizar operaciones aritméticas y volver a operar sin necesidad de reiniciar el programa.

Objetivo: combinar variables, entradas de datos, condicionales, ciclos y manejo de errores.

Proyecto 10.2: Juego de adivinanzas

Crear un juego en el que el usuario deba descubrir un número secreto, con un número limitado de intentos.

Objetivo: integrar ciclos, condicionales y lógica de programación.

Proyecto 10.3: Gestor de tareas

Desarrollar un programa que permita agregar, consultar y eliminar tareas.

Objetivo: practicar listas, ciclos, condicionales y funciones.

🎯 Recomendaciones para aprender

Intenta resolver los ejercicios sin consultar una solución inmediatamente.

No te limites a copiar el código: asegúrate de comprender qué hace cada instrucción.

Experimenta cambiando valores y condiciones para observar cómo se comporta el programa.

Si encuentras un error, intenta identificar su causa antes de buscar una solución.

Practica con regularidad y avanza a tu propio ritmo.
